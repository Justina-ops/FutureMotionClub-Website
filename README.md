# FutureMotion Club Website

An eight-page website for an animation and multimedia club, developed as a group assignment for UCCD2323 Front-End Web Development at UTAR.

## Live Website

[Visit FutureMotion Club](https://justina-ops.github.io/FutureMotion-Club/)

## Overview

The website brings together club information, creative projects, artwork, tutorials and events. Visitors can explore multimedia content and learn about the club through a shared navigation menu.

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery
- GitHub Pages

## Website Pages

| Page | Purpose |
| --- | --- |
| Home | Introduces the club and featured content |
| About | Provides background information about the club |
| Projects | Showcases animation and multimedia projects |
| Gallery | Displays artwork and visual references |
| Tutorials | Provides learning resources |
| Events | Presents club events and activities |
| Multimedia | Showcases multimedia content |
| Contact | Provides contact information |

## Running Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Use the Live Server extension to open `index.html`.

An internet connection is needed for externally hosted libraries and embedded content.
